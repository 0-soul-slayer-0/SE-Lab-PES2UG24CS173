## Running the Python labs

Use Python 3.10 or later. Install the coverage and fuzz-testing dependencies from the repository root:

```sh
python3 -m pip install -r requirements.txt
```

Run the Lab 6 and Lab 7 tests separately from their respective folders; they use different applications with the same module name. Each folder README includes the commands. The Lab 4 application has its own requirements in `reaction-time-tester/requirements.txt`.
